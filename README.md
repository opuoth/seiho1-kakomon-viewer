# 生保1 過去問DBビューア β版（v0.1.4-beta）

生保1の過去問6年分を、テーマ・問われ方・教科書見出し単位で横断して見るための学習ビューアです。
設問を選ぶと、問題文・教科書該当箇所・解答をすぐ切り替えられます。

## できること

- 過去問DBを年度・テーマ・キーワードで検索
- 設問ごとに、問題PDFの該当ページを表示
- 教科書PDFの該当見出しページを表示
- 「解答」ボタンで解答ページに切替
- PCでは2ペイン表示、スマホでは1ペイン表示
- スマホではページ画像表示により、幅フィット・縦スクロールで閲覧

## 起動方法

### Windows / PC

1. ZIPを展開します。
2. `open_viewer.bat` または `開く_ビューア.bat` をダブルクリックします。
3. ブラウザで `index.html` が開きます。

うまく開かない場合は、`index.html` を直接ブラウザで開いてください。

### スマホ

スマホでは、ZIPを展開したフォルダ構成を崩さずに `index.html` をブラウザで開いてください。
端末・ブラウザによってローカルHTMLの動作に差があります。安定運用する場合は、限定公開の静的サイトとして配置する方法を推奨します。

## フォルダ構成

```text
.
├─ index.html
├─ kakomon_dual_viewer.html
├─ open_viewer.bat
├─ 開く_ビューア.bat
├─ seiho1_kakomon_db_2020_2025_textbook_links.xlsx
├─ exams/        # 過去問PDF
├─ textbooks/    # 教科書PDF
└─ page_images/  # スマホ表示用ページ画像
```

## 限定共有時の注意

このパッケージにはPDFファイルを同梱しています。まずは自分用・限定共有のβ版として扱ってください。
一般公開する場合は、PDFを同梱しない公開版に分け、利用者が各自で正規に入手したPDFを配置する方式にしてください。

## 推奨ブラウザ

- PC: Microsoft Edge / Google Chrome
- スマホ: Chrome / Safari

## 既知の制約

- ブラウザや端末によって、ローカルファイル `file://` の表示に制限がある場合があります。
- PC表示ではブラウザ内蔵PDFビューアの仕様により、PDFのページジャンプやツールバー表示が環境依存になる場合があります。
- スマホ表示はページ画像ベースのため、表示対象のページ画像が同梱されている範囲で閲覧できます。


## v0.1.4-beta 追加機能

PC/ブラウザ表示では、画面上部の「PDF幅」と「問題/右」スライダーで表示サイズを調整できます。

- **PDF幅**：左の過去問DB一覧と、右のPDF表示エリアの比率を変更します。
- **問題/右**：問題PDFと、右側の教科書/解答PDFの左右比率を変更します。
- **リセット**：初期値に戻します。

スマホ表示では従来どおり、PDFは1つずつ切り替えて表示します。


## v0.1.4-beta 追加機能

PC/ブラウザ表示では、スライダーではなく境界部分をドラッグして表示サイズを調整できます。

- **過去問DB一覧とPDF表示エリアの境界**：ホバーすると調整用のラインが表示され、左右にドラッグできます。
- **問題PDFと教科書/解答PDFの境界**：ホバーすると調整用のラインが表示され、左右にドラッグできます。
- **ダブルクリック**：それぞれの境界をダブルクリックすると初期幅に戻ります。
- 調整値はブラウザのlocalStorageに保存されます。

スマホ表示では従来どおり、PDFは1つずつ切り替えて表示します。
